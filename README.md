A make.fun entry for the **Funniest Time Machine Warning Label** bounty: a
single one-line warning label for a time machine, written as dry official
safety copy — the grandfather paradox as a refund policy, with the sting
saved for the last two words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (stdlib-only, Python 3.13) writes the label to `entry.txt` inside
the directory named by `MAKEFUN_OUTPUT_DIR` (falling back to `.` when unset).
The output is one line, UTF-8, 103 characters, with no trailing newline.
